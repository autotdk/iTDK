Bắt đầu

Cài đặt trong ba bước

Tải file về

Bấm nút vàng ở đầu trang. Chỉ có một file iTDK.exe, không có bộ cài.

Đặt vào thư mục thường

Ví dụ D:\iTDK hoặc ngay trên Desktop. Đừng để trong Program Files — Windows không cho tool tự cập nhật ở đó.

Mở game trước, rồi mở tool

Tool tự tìm các cửa sổ game đang chạy và hiện thành danh sách. Tick nhân vật muốn chạy, chọn việc, bấm Bắt đầu.

Nếu Windows Defender báo file nguy hiểm: tool đọc và ghi bộ nhớ của tiến trình game để điều khiển nhân vật — đúng cái mà phần mềm diệt virus được dạy để chặn. Thêm ngoại lệ cho thư mục chứa iTDK.exe rồi tải lại, hoặc chọn "Giữ lại" (Keep) trong hộp thoại cảnh báo của trình duyệt.
Hỏi đáp

Câu hỏi hay gặp

Có cần cài .NET hay thư viện gì không?

Không. Toàn bộ tool nằm trong một file iTDK.exe, viết bằng C++ thuần và chỉ dùng thư viện có sẵn của Windows. Tải về là chạy được ngay.

Cập nhật bản mới thế nào?

Không phải làm gì cả. Mỗi lần mở lên, tool tự hỏi máy chủ xem có bản mới không; có thì hiện hộp thoại, bấm Cập nhật là nó tự tải, tự thay và mở lại.

Riêng những bản đánh dấu bắt buộc thì không có nút "Để sau" — thường là khi game vừa vá và bản cũ đã chạy sai, chạy tiếp lúc đó rất dễ mất tài khoản.

Chạy được bao nhiêu cửa sổ game cùng lúc?

Không giới hạn từ phía tool — mỗi cửa sổ game là một dòng trong danh sách. Giới hạn thật nằm ở RAM và CPU máy bạn, vì mỗi cửa sổ game là một tiến trình riêng.

Đặt trong Program Files có sao không?

Tool vẫn chạy, nhưng đến lúc tự cập nhật thì Windows chặn việc ghi đè và tool sẽ báo lỗi. Đặt ở thư mục thường (Desktop, D:\iTDK…) thì mọi thứ trơn tru.
